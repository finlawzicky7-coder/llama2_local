## Compliance officer's working set (read these in this order each AEP)

1. `pre-launch-checklist.md` — gate all activity behind this.
2. `tpmo-disclaimer.md` — confirm version live everywhere.
3. `consent-language.md` — confirm every consent capture matches.
4. `audit-procedures.md` — confirm continuous audits running, calendar quarterly reviews.
5. `../sales/scripts/aep-followup.md` — the AEP-specific operating doc.
6. `../docs/01-architecture.md` — for any cross-system question.

## Sources to keep current

- CMS Medicare Communications and Marketing Guidelines (MCMG) — re-read every plan year.
- TCPA / FCC Part 64 — track FCC consumer-and-governmental-affairs-bureau orders.
- Federal Do-Not-Call Registry rules.
- TSR (Telemarketing Sales Rule).
- Each state's insurance-marketing rules where you operate.
- Each state's call-recording consent rules.
- Each carrier's marketing rules (often stricter than CMS).
- Your FMO's compliance bulletins.
