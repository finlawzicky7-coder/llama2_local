## 5. Budget & Bidding Strategy

### Launch Budget (Month 1)
| Phase | Daily Budget | Monthly | Objective |
|-------|-------------|---------|-----------|
| Testing (Week 1-2) | $100-150/day | $1,400-$2,100 | Test 5-8 ad variations |
| Scaling Winners (Week 3-4) | $200-400/day | $2,800-$5,600 | Scale top 2-3 performers |
| **Total Month 1** | | **$4,200-$7,700** | |

### Bidding Strategy
- **Testing**: Lowest Cost (let Meta optimize)
- **Scaling**: Cost Cap at target CPA ($25-$40)
- **Retargeting**: Lowest Cost (smaller audiences, lower CPMs)

### Key Metrics to Track
| Metric | Target | Alert If |
|--------|--------|----------|
| CPA (Purchase) | <$35 | >$50 |
| ROAS | >3.0x | <2.0x |
| CTR (Link) | >1.5% | <0.8% |
| Hook Rate (3s views) | >30% | <20% |
| ThruPlay Rate | >15% | <8% |
| Add to Cart Rate | >8% | <4% |
| Purchase Conv. Rate | >2.5% | <1.5% |

### Scaling Rules
- **Scale UP** if: ROAS > 3.5x for 3 consecutive days → increase budget 20-30%
- **Hold** if: ROAS 2.5-3.5x → maintain, test new creative
- **Scale DOWN** if: ROAS < 2.0x for 2+ days → reduce budget 30%, test new creative
- **Kill** if: ROAS < 1.5x for 3+ days with $200+ spend → pause and iterate

## 8. Creative Specs & Best Practices

### Video Specs
| Placement | Ratio | Resolution | Duration |
|-----------|-------|-----------|----------|
| Reels | 9:16 | 1080x1920 | 15-30s (sweet spot) |
| Stories | 9:16 | 1080x1920 | 15s per card |
| Feed | 1:1 | 1080x1080 | 30-60s |
| In-Stream | 16:9 | 1920x1080 | 15-30s |

### Image Specs
| Placement | Ratio | Resolution |
|-----------|-------|-----------|
| Feed | 1:1 | 1080x1080 |
| Carousel | 1:1 | 1080x1080 |
| Stories | 9:16 | 1080x1920 |

### Creative Best Practices

1. **Hook in 0-3 seconds** — Use pattern interrupts: bold text, unexpected visuals, provocative statements
2. **Sound-off first** — 85% watch without sound. Use bold text overlays for all key info
3. **Native feel** — Make ads look like organic content, not polished commercials
4. **Social proof early** — Show ratings, review count, or customer UGC within first 5 seconds
5. **Clear CTA** — Always show what to do next. "Link in bio," "Shop now," "Tap to learn more"
6. **Test 3-5 hooks** per concept — Same body, different openings. Hook determines 80% of performance
7. **Iterate weekly** — Refresh creative every 7-14 days to fight ad fatigue
8. **UGC > Polished** — Authentic, phone-shot testimonials outperform studio content 2-3x

### A/B Testing Framework
Test in this order (one variable at a time):
1. **Hook** (biggest impact) — test 3-5 opening lines/visuals
2. **Audience** — test 2-3 interest stacks per creative
3. **Offer** — 15% off vs free shipping vs bundle discount
4. **Format** — Reel vs Carousel vs Single image
5. **CTA** — "Shop Now" vs "Learn More" vs "Get Offer"
