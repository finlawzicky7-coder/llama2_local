# Outreach Templates

Copy-paste, personalize the bracketed tokens. These live in the repo so
every operator is using the tested version.

> running back-to-back bookings this month. I run Turnover916, a Sacramento
> cleaning crew that specializes in Airbnb turnovers. Flat rate ($85 for a

> you never have to wonder whether the unit is guest-ready.
>
> If you want to try us once with no commitment, reply "yes" and I'll text
> you the booking link.
>
> — [Your name]
